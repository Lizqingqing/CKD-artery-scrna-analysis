# Environment and dependencies

## Recommended approach

Use a fresh R project/library and a supported matching R/Bioconductor release. Seurat >=5 and SeuratObject >=5 are required by this code. This is an API target, not a tested full dependency combination. Monocle3 and scMetabolism have substantial compiled and transitive dependencies; consult their current official installation instructions when resolving platform-specific failures.

Typical system requirements include a C/C++/Fortran toolchain, libcurl, OpenSSL, XML, and geospatial libraries required by sf/units (GDAL, GEOS, PROJ, UDUNITS2). On macOS use the appropriate Xcode command-line tools and R-compatible compiler toolchain. On Windows use matching Rtools; Linux users should install distribution-specific development libraries. Do not copy a lockfile across incompatible R/platform combinations without testing.

## Explicit source selection

Run the bootstrap with reviewed commit SHAs or release tags. Values below are placeholders and must be replaced:

```sh
Rscript scripts/install.R SC_METABOLISM_REF MONOCLE3_REF VISION_REF
```

The installer does not invent a scMetabolism v1.0 tag. If your collaborator supplies a genuine local source archive, install it using `install.packages("/path/package.tar.gz", repos = NULL, type = "source")` and install its declared dependencies; skip the corresponding GitHub install. Check `packageVersion("scMetabolism")` and the source's API. Version equality alone cannot establish API compatibility with an unavailable release.

If you intentionally adopt upstream 0.2.2 instead, select a reviewed commit that reports 0.2.2, set `metabolism.expected_version: '0.2.2'`, and update the manuscript accordingly. Inspect `packageDescription("scMetabolism")` for `RemoteSha` and preserve installation logs. The source examined uses `sc.metabolism(countexp, method, imputation, ncores, metabolism.type)` and a bundled KEGG GMT; a different release must be checked against that contract.

The upstream README recommends VISION v3.0.2 as an installation option. Although this pipeline uses AUCell only, VISION/GSVA are still declared scMetabolism imports. The bootstrap installs all imports, not merely the functions called here. No automatic dependency upgrades occur during analysis.

## Capture a reproducible environment

After installation and a representative successful full analysis:

```r
renv::init(bare = TRUE)
renv::snapshot(type = "all", prompt = FALSE)
```

Review and commit `renv.lock`, `renv/activate.R`, `renv/settings.json`, and `.Rprofile` generated by renv. Confirm the lock records GitHub commit SHAs and then test `renv::restore()` in a clean library. Do not commit `renv/library/` or raw datasets. If already using renv, initialize before installation and snapshot afterward.

Capture `sessionInfo()`, package versions, source refs, and the KEGG GMT checksum in the study archive. The pipeline already writes session/package data for each attempted stage and a GMT checksum when metabolism preflight succeeds. For raw data provenance, preserve provider checksums and a checksum manifest of all original matrix files separately.

## Resource planning

Start with a representative subset. AUCell ranking in the upstream scMetabolism implementation converts expression to dense matrices. A 30,000-gene by 50,000-cell double matrix alone is approximately 11.2 GiB, before rankings and temporary allocations. The configured memory estimate is conservative but approximate. This workflow intentionally does not silently split scoring into chunks or subsample cells, which could change reproducibility and tie handling.
